# java-lotto-precourse

# 로또 🎰

## 로또 발매기 기능

**1. 로또 발행**

- 구입 금액에 해당하는 만큼 로또를 발행한다 (1장당 1000원)
- 1~45사이의 번호를 중복없이 6개 뽑는다

**2. 당첨 번호 발행**

- 1~45사이의 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다

**3. 당첨 확인**

```text
1등: 6개 번호 일치 / 2,000,000,000원
2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
3등: 5개 번호 일치 / 1,500,000원
4등: 4개 번호 일치 / 50,000원
5등: 3개 번호 일치 / 5,000원
```

- 로또 번호와 당첨 번호를 비교한다
- 당첨 내역 및 수익률을 출력한다

## 추가 고려 사항

- 로또의 1회 최대 구매 가능 금액은 100,000이다.
- 당첨 번호 입력받을 때 숫자 앞뒤의 공백은 가능, 나머지는 예외 처리
- 보너스 번호도 숫자 앞뒤 공백은 허용

## 💭개발하면서 고민했던 부분

### 클래스의 역할

이번 과제에서는 클래스가 하나의 역할을 맡도록 고민하며 구현했습니다.

```text
lotto
├── controller
│   └── LottoManager.java
├── domain
│   ├── Lotto.java
│   ├── LottoMachine.java
│   ├── LottoResult.java
│   ├── LottoStatistics.java
│   └── Rank.java
├── util
│   └── ErrorMessages.java
└── view
    ├── InputView.java
    └── OutputView.java
```

### controller

**LottoManager**

로또를 실행하는 역할의 클래스입니다.

Application의 main에 작성하고 보니 main 보다는 실행을 담당하는 클래스를 작성하는 게
흐름 제어라는 역할을 분리할 수 있어 LottoManager 클래스를 분리했습니다.

### domain

로또와 관련한 비즈니스 로직을 담당하는 클래스를 묶은 패키지입니다.

**Lotto**

'로또'를 담당하는 클래스로 이해하고 메서드를 추가했습니다.

기존의 validate 메서드에 1~45 사이의 숫자인지 검증하는 validateRange()와 validateDuplicate()를 추가해
로또에 중복되는 번호가 있는지 확인하도록 구현했습니다.

로또를 정렬하거나 포함된 번호가 있는지 확인하는 로직, 일치하는 개수를 구하는 로직은
Lotto 내부에서 구하고 밖에서는 결과만 알 수 있도록 작성했습니다.

**LottoMachine**

로또를 발급하는 역할을 담당하는 클래스입니다.

입력받은 금액으로 몇 장을 발급할지 구하고, 구매 개수만큼 로또를 발급합니다.
이때 생성되는 로또는 Lotto 생성자에서 검증과 정렬이 완료됩니다.

**LottoResult**

로또의 결과를 확인하는 클래스입니다.

구매한 로또를 하나씩 확인하면서 일치하는 번호의 개수와 보너스 번호의 일치 여부를 찾고
results에 결과를 담습니다.

각 Rank별로 몇 개 당첨됐는지 확인하기 위해 Map을 이용했습니다.

**LottoStatistics**

수익률 계산을 담당하는 클래스입니다.

총수익 계산은 `mapToLong`을 활용하고, 소수점 둘째 자리에서 반올림해야 하므로 double로 반환하도록 구현했습니다.

**Rank**

당첨금과 관련한 정보를 담고, 이를 찾는 로직을 담은 Enum입니다.

1~5등까지의 정보를 넣고 이에 해당하지 않는 경우는 NONE을 반환하도록 구현했습니다.

**ErrorMessages**

에러 메시지를 상수화한 Enum입니다.

**InputView & OutputView**

각각 입력과 출력을 담당하는 클래스입니다.
