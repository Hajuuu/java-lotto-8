# java-lotto-precourse

# 로또 🎰

## 로또 발매기 기능

**1. 로또 발행**
- 구입 금액에 해당하는 만큼 로또를 발행한다 (1장당 1000원)
- 1~45사이의 번호를 중복없이 6개 뽑는다

**2. 당첨 번호 발행**
- 1~45사이의 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다

**3. 당첨 확인**
```text
1등: 6개 번호 일치 / 2,000,000,000원
2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
3등: 5개 번호 일치 / 1,500,000원
4등: 4개 번호 일치 / 50,000원
5등: 3개 번호 일치 / 5,000원
```
- 로또 번호와 당첨 번호를 비교한다
- 당첨 내역 및 수익률을 출력한다


## 구현 목록
- [ ] 입력
  - [ ] 구입 금액
  - [ ] 로또 번호
  - [ ] 보너스 번호
  - [ ] 잘못된 값 입력 시 [ERROR] 로 시작하는 에러 문구 출력
- [ ] 로또 발행
  - [ ] 금액을 통해 발행 장수 구하기
  - [ ] 1~45 중 중복 없이 6개 뽑음
- [ ] 당첨 번호 발행
  - [ ] 1~45 중 중복 없이 6개 뽑고 1개 더 뽑아서 보너스 숫자로 관리
- [ ] 당첨 확인
  - [ ] 각 등수에 대한 정보
  - [ ] 로또 번호와 당첨 번호 비교해서 해당하는 등수 확인
  - [ ] 수익률 계산(소수점 둘째 자리에서 반올림 ex. 51.5%)
- [ ] 출력
  - [ ] 로또 안내문 출력
  - [ ] 당첨 통계 출력

## 추가 고려 사항
- 로또의 1회 최대 구매 가능 금액은 100,000이다.
